# 🌐 Aplicación Web REST

Proyecto backend desarrollado con Spring Boot para practicar servicios web, persistencia de datos, seguridad y documentación de API.

## Tecnologías

Java 21 · Spring Boot · Spring Web · Spring Data JPA · MySQL · Spring Security · Swagger/OpenAPI · Maven.

## Enfoque

Aplicación backend estructurada con Spring Boot, persistencia mediante JPA y MySQL, mecanismos de seguridad y documentación de API.

## Ejecución

Configura MySQL y las propiedades de la aplicación.

```bash
mvnw.cmd spring-boot:run
```
